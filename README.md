# LocalOptima analytics

The homepage and privacy policy for LocalOptima analytics, a private tool that records the Local Optima YouTube channel's own statistics. Google requires both pages before an OAuth app can leave Testing.

- Homepage: https://pdudleydev.github.io/localoptima-analytics/
- Privacy policy: https://pdudleydev.github.io/localoptima-analytics/privacy.html

The tool itself is not in this repository.
