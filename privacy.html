Privacy policy

LocalOptima analytics · Last updated November 5, 2026

LocalOptima analytics is a private tool that records the Local Optima YouTube channel's own statistics for the channel's owner. It is used only with the channel's own Google account.

YouTube API Services

The tool uses YouTube API Services. Anyone who signs in to it agrees to the YouTube Terms of Service, and Google's handling of the data is covered by the Google Privacy Policy.

What it accesses

At sign-in it asks for two read-only permissions:

  • youtube.readonly, to list the channel's public videos with their titles, lengths, release times and public view, like and comment counts;
  • yt-analytics.readonly, to read the channel's YouTube Analytics and Reporting data: views, watch time, average view duration, subscribers gained and lost, likes, comments, shares, traffic sources, audience retention, impressions and click-through.

It can't upload, edit or delete videos, change channel settings, or post, reply to or moderate comments. It doesn't read private messages, viewers' identities, or anything outside the channel's own statistics.

How the data is used

Only to keep a record of how the channel's videos perform, for the channel's owner. Nothing is used for advertising.

Where it's stored

The statistics are saved as files in the channel owner's own working files, on their computer and in a private backup. The sign-in token is kept only on the owner's computer. The tool has no server, database or user accounts of its own.

Sharing

The data isn't sold, rented or shared with anyone else. The owner may choose to publish some of the channel's own numbers, as any creator might.

How long it's kept

The statistics are the channel's own history and are kept as long as the channel runs. Revoking access stops all further collection.

Revoking access

Access can be removed at any time on Google's security settings page, by removing LocalOptima analytics from the list of connected apps.

This website

This site is hosted on GitHub Pages. It sets no cookies and runs no tracking. GitHub may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Changes and contact
